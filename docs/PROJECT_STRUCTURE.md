# Структура проекта

```text
police_dashboard_appscript/
  appsscript.json
  src/
    menu/
    dashboard/
    reports/
    services/
    config/
    utils/
  docs/
```

## Логика разделения

`menu` - точки входа и кнопки меню.

`dashboard` - экраны, сводки и действия дашборда.

`reports` - генераторы отчетов.

`services` - получение, сборка и подготовка данных.

`config` - названия листов, колонок, статусы и константы.

`utils` - общие функции: даты, текст, проверки.

## Правило разработки

Новая фича должна цепляться к конкретному блоку. Если фича касается отчета, сначала правится `reports`. Если фича касается данных, сначала правится `services`. Если изменилась колонка или лист, правится `config`.
