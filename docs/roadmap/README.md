# Versioned Development Roadmap

Этот раздел фиксирует методологию и поэтапное развитие Police Service.

## Порядок чтения
1. `DEVELOPMENT_PROCESS.md` - как мы разрабатываем.
2. `ARCHITECTURE_OVERVIEW.md` - общая архитектура.
3. `TECHNICAL_ARCHITECTURE.md` - технические слои и зависимости.
4. `COMPONENTS_AND_CONTRACTS.md` - компоненты и repository contracts.
5. `TEST_AND_DONE.md` - качество, тесты и Definition of Done.
6. `versions/` - подробная спецификация каждой версии.
7. `ARCHITECTURE_DECISIONS.md` - принятые архитектурные решения.

## Roadmap
- v0.1 Foundation
- v0.2 Trip Planning Core
- v0.3 Legacy Read Integration
- v0.4 Decision Support & Messages
- v0.5 Operational Dashboard
- v1.0 Corporate Production

Каждая версия должна быть работающим vertical slice и завершаться acceptance review, demo и Git tag.
