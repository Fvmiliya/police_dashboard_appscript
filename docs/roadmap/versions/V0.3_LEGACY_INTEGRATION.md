# v0.3 - Legacy Read Integration

## Goal
Подключить Police domain к существующим данным без глобальной миграции legacy.

## Scope
Driver, contacts, assignment, vehicle and manager adapters; normalization; data-quality validation; contract tests; read-only integration contracts.

## Principle
`Legacy schema -> Mapper -> Clean domain object`.

## Stages
1. Зафиксировать exact field mapping и типы.
2. Проверить driver identity: missing/duplicate business IDs.
3. Нормализовать основной водитель/стажер/замена в единый `VehicleAssignment`.
4. Нормализовать board code.
5. Привести разные manager/source schemas к `VehicleResponsibility`.
6. Написать contract tests.

## Acceptance criteria
По `driverId + tripDate` система возвращает driver, contacts, assignment либо null, board и manager либо явную Data Quality ошибку.

## Learning focus
Anti-corruption layer, adapters/mappers, business key vs technical ID, temporal queries, contract tests and data quality.

## Exit
Tag `v0.3.0`.
