# Future Roadmap

После v1.0 развитие идет только при подтвержденной бизнес-ценности.

## v1.1 - Notifications
Email/Teams/Power Automate, persistent lifecycle, idempotency, retry, sent/failed states and audit snapshots.

## v1.2 - Documentation Process Integration
Интеграция с существующим процессом документов только после reverse engineering текущих flows и side effects.

## v1.3 - Analytics
Operational KPI, trends and Power BI if needed.

## v2.x - Data Platform
API/PostgreSQL только если появятся реальные требования: сложные joins, транзакции, несколько потребителей, SharePoint performance limits, централизованный data quality/audit или несколько модулей на общей domain model.
