# v0.4 - Decision Support & Messages

## Goal
Закончить основной operational workflow после создания поездки.

## Main flow
- participant -> assignment -> board -> manager -> manager message;
- participant -> no assignment -> contacts -> driver message.

## Scope
Participant resolution, on/off vehicle state, board and manager display, contacts, data-quality warnings, manager message, driver message, copy action and grouping participants by manager.

## Stages
1. `ParticipantResolutionService`.
2. Explicit DQ/error model.
3. Message templates.
4. Manager grouping.
5. Operational participant cards in UI.
6. Copy workflow.
7. Edge-case tests.

## Non-goal
No automatic email/Teams/Power Automate sending.

## Acceptance criteria
Для каждого участника система выдает один ясный результат: готовая заявка ведущему, сообщение водителю с контактами, либо блокирующая Data Quality ошибка.

## Learning focus
Service orchestration, branching business rules, derived views, templates and error modeling.

## Exit
Tag `v0.4.0`.
