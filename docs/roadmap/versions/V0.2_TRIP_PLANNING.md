# v0.2 - Trip Planning Core

## Goal
Получить первый реальный vertical slice: создать поездку с 1..N водителями и просмотреть ее по дате/периоду.

## Scope
`PoliceTrip`, `TripParticipant`, create/edit, city, appointment time, reason, case number, route ordering, departure = earliest - 90 min, day view and period view.

## Stages
1. Domain entities and validation.
2. Persistence for trips and participants.
3. Use cases: create/update/get by date/get by period.
4. `RouteService` with deterministic sorting.
5. Create-trip UI with add/remove participant.
6. Day and range views.

## Critical tests
One driver, many drivers, multiple cities, same earliest time across cities, same participant time inside one city, departure calculation.

## Acceptance criteria
Пользователь может создать поездку с одним или несколькими водителями, а система без ручной сортировки показывает правильный маршрут и время выезда.

## Learning focus
Domain modeling, 1:N, use cases, pure functions, deterministic algorithms, React state and unit testing.
