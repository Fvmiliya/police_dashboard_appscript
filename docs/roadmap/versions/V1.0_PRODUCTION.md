# v1.0 - Corporate Production

## Goal
Перенести доказанный PoC в поддерживаемую корпоративную среду без переписывания business logic.

## Scope
Approved corporate frontend deployment, production adapters, corporate storage for trips/participants, identity, permissions, audit, logging, configuration, UAT, deployment and rollback procedure.

## Stages
1. Production design review: ownership, sources, permissions, deployment path.
2. Infrastructure adapters: PoC repositories -> corporate repositories.
3. Identity/security: corporate identity, no self-selected privileges.
4. Controlled migration only if PoC data must be preserved.
5. UAT in test environment.
6. Production deployment, smoke test, monitoring.

## Production gates
Authorization approved, no personal data in personal/test tenants, hidden automation side effects understood before writes, audit/logging present, rollback documented.

## Acceptance criteria
Инструмент работает на разрешенных corporate sources, принят бизнес-пользователями и имеет понятную процедуру поддержки и восстановления.

## Learning focus
Production integration, authentication/authorization, UAT, observability, release management and rollback.
