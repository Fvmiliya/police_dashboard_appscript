# v0.5 - Operational Dashboard

## Goal
Сделать инструмент удобным для ежедневной работы и демонстрации руководству.

## Scope
Today/Tomorrow/Week, custom date range, driver/city/reason/status filters, driver history, edit/cancel, loading/empty/error states, data-quality badges, performance work, regression suite and demo fixtures.

## Stages
1. Query/read model.
2. Dashboard filters.
3. Driver history.
4. Edit/cancel workflow.
5. UI polish.
6. Performance and caching where justified.
7. Regression suite.
8. Management demo scenario.

## Acceptance criteria
HR может создать, найти, отфильтровать, проверить, открыть историю и исправить поездку без работы с raw storage.

## Learning focus
Read models, operational UX, filtering, performance, audit metadata and regression testing.

Tag `v0.5.0`.
