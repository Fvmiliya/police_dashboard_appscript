# v0.1 - Foundation

## Goal
Создать профессиональный каркас, на котором следующие версии добавляются без переписывания архитектуры.

## Scope
TypeScript/React/GAS shell, build command, typed API boundary, repository interfaces, synthetic fixtures, unit-test setup, base error model and documentation baseline.

## Stages
1. Repository baseline: package manager, tsconfig, lint/format, test runner, build scripts.
2. Layer skeleton: domain/application/repositories/infrastructure/web/server.
3. Typed transport boundary between React and Apps Script.
4. Synthetic data for drivers, contacts, assignments, vehicles and managers.
5. Smoke build and documented local/deploy procedure.

## Non-goals
No real legacy integration, trip workflow or production auth.

## Acceptance criteria
- one command builds the project;
- Web App opens;
- tests run locally;
- platform APIs do not leak into domain/application;
- fixtures contain no real PII.

## Learning focus
Layering, dependency inversion, repository pattern, TypeScript interfaces, Git flow, ADR and build pipeline.

## Exit
Tag `v0.1.0`.
